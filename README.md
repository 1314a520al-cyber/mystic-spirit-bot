# TK全能机器人 - AstrBot 插件

## 功能

- 🔐 用户系统+权限（注册/登录验证码/二级密码/四级权限）
- 🤖 AI 聊天（内置免费API，支持自定义）
- 📁 文件管理+全文搜索（转发文件自动保存，关键词搜索内容）
- 📦 存储功能（键值对云存储）
- 🛠 实用工具（天气/翻译/骰子/签到）

## 安装

1. 下载 `astrbot_plugin_tkbot.zip`
2. AstrBot 面板 → 插件 → 上传插件 → 选 zip
3. 启用插件
4. Telegram 发 `/register 你的密码` 注册
5. 发 `/initowner` 成为创建者（最高权限）
6. `/help` 查看所有命令

## 命令

见 `/help` 命令输出。
